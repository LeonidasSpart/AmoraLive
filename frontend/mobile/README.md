# AmoraLive Mobile

Expo / React Native client foundation for iOS, Android and iPad.

Production API: `https://api.amoramatch.one`

This app uses the same backend authentication, matching, messaging, Live, wallet, gifts and membership APIs as the web client. Authentication tokens are stored with Expo SecureStore.

Before store submission, finish native LiveKit/WebRTC and Apple/Google in-app purchase verification using the same server-side entitlement rules as the web platform.
