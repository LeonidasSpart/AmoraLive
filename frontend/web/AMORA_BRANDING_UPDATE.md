# AmoraLive Branding & Responsive Web Update

Implemented in the web frontend:
- Official Amora logo assets and brand mark.
- Pink-to-purple Amora brand palette across public and authenticated web shell.
- Responsive landing page for desktop, laptop, tablet, iPad and mobile.
- Responsive login page with Google OAuth entry and email/username login.
- Brand favicon, Apple touch icon and web manifest.
- Authenticated Layout now uses the Amora logo and shared brand variables.
- Mobile-safe spacing, controls, typography and reduced-motion support.

Production domain assumptions:
- Web: https://www.amoramatch.one
- API: https://api.amoramatch.one
- Optional frontend variable: NEXT_PUBLIC_API_URL=https://api.amoramatch.one
